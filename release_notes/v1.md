# Security AI Agent UI (`security-agent-ui`)

## Executive Overview
`security-agent-ui` is a modern, responsive web application built with **React 18**, **TypeScript**, **Vite**, and **Tailwind CSS v4**. It interfaces directly with the `security-agent-base` REST API, featuring a **ChatGPT-style left sidebar**, **instant dynamic session creation**, **SQLite history sync**, an **auto-scrolling chat window**, and an interactive **Human-in-the-Loop (HITL) approval banner**.

---

## 1. System Architecture & Features

```text
 ┌────────────────────────────────────────────────────────────────────────┐
 │                        security-agent-ui (React 18)                    │
 ├───────────────────────────────────┬────────────────────────────────────┤
 │  Sidebar Session Browser          │  Interactive Chat View             │
 │  - "+ New Chat" Button            │  - Real-time message streaming     │
 │  - Session List & Message Count   │  - Auto-scrolling (useRef)         │
 │  - Session Delete (Trash Icon)    │  - HITL Interrupted Action Banner  │
 └───────────────────────────────────┴────────────────────────────────────┘
```

### Key Technical Features
* **ChatGPT-Style Sidebar Session Navigation**: Displays all active conversation threads stored in SQLite alongside message count metrics, allowing instant session switching.
* **Instant Dynamic Session Creation**: Generates new thread IDs on demand without losing unsaved initial states.
* **Human-in-the-Loop Approval Banner**: When high-risk tool operations (`publish_security_advisory`) are paused by the backend, an amber alert banner renders directly in the chat view with **Approve Execution** and **Reject Action** buttons.
* **Session Lifecycle Controls**: Clear conversation history or delete chat sessions completely directly from the interface.
* **10-Second Health Polling Loop**: Automatically pings `GET /health` to display live server connectivity status (**Online (8000)** vs **Offline**).

## 3. Key Component Architecture

### A. Root Layout & Sidebar (`src/App.tsx`)
* Manages `activeThreadId` state and fetches active threads via `listThreads()`.
* Combines unsaved new threads dynamically into the session sidebar so brand-new sessions aren't lost before sending the first message.
* Handles session deletion triggers and switches active session seamlessly.

### B. Interactive Chat Window (`src/components/ChatWindow.tsx`)
* **Thread History Sync**: Fetches historical message logs from `database.db` via `fetchThreadHistory(threadId)` whenever the active session changes.
* **Smooth Auto-Scroll**: Uses a React `useRef` anchor (`messagesEndRef`) that executes `scrollIntoView({ behavior: 'smooth' })` when new messages render or loading states toggle.
* **HITL Action Banner**: Conditionally renders an amber notification when `pendingAction` is present, sending approval or rejection payloads to `POST /agent/approve`.

## 4. Setup & Operations

### Environment Variable (`.env`)
Create a `.env` file in the project root:
```env
VITE_API_BASE_URL=http://localhost:8000
```

### Installation & Launch Commands
```powershell
# 1. Install dependencies
npm install

# 2. Launch local development server (http://localhost:5173)
npm run dev

# 3. Build for production
npm run build
```
